# UI/UX Pro Max Design Intelligence

## Core Design System & Reasoning Rules

1. **Pre-Delivery UI/UX Checklist (Mandatory for all UI changes)**
   - [ ] No emojis used as UI icons (use standard SVGs or icon libraries like Lucide/Heroicons).
   - [ ] `cursor-pointer` applied on all clickable elements (buttons, links, cards).
   - [ ] Smooth transitions on interactive states (hover/focus durations between 150ms-300ms).
   - [ ] Contrast ratio meets WCAG AA standards (minimum 4.5:1 for normal text).
   - [ ] Visible focus indicators for keyboard navigation and accessibility.
   - [ ] `prefers-reduced-motion` media queries respected where complex animations are used.
   - [ ] Fully responsive across standard viewports (375px mobile, 768px tablet, 1024px desktop, 1440px wide).

2. **Aesthetic & Anti-Pattern Avoidance**
   - **Avoid**: Generic plain colors, harsh instant state changes, clashing neon gradients, and oversaturated purple/pink AI clichés unless requested.
   - **Prioritize**: Curated harmonious color palettes, subtle depth/soft shadows, organic glassmorphism, and intentional typography pairings.

3. **Pattern & Layout Selection**
   - Match layout patterns (Hero-centric, Masonry, Split-screen, SaaS Dashboard) to the product's domain.
   - Ensure clear visual hierarchy with primary call-to-actions (CTAs) immediately visible above the fold.
